# gooaye-perspective

股癌 Gooaye / 謝孟恭的投資、產業觀察、生活判斷與表達操作系統。

這是一個 Codex/Hermes-style skill，基於本機 EP1-EP708 逐字稿與公開資料蒸餾，用來在使用者明確要求「股癌視角」「主委會怎麼看」「Gooaye perspective」時，輸出灰階、產業鏈、部位、風險與生活配置式的判斷框架。`whatmkreallysaid.com` 公開稿目前已同步到 EP702；EP703-EP707 是 SoundOn `faster-whisper-medium` CPU `int8` 暫定稿，EP708 是同模型 CUDA `float16` 暫定稿，並保留各集 `EP*.raw.*` 作為溯源。EP704 新增曼報 Pro 與創作者邊界、圈子改寫風險基準、OpenAI 年化營收取樣、Marvell 互聯／光通 roadmap、BMC total solution 與 All Weather Portfolio 的人生階段；EP705 新增擁擠交易的預期差與籌碼清洗、企業 AI ROI、AI 研究入口、瓶頸漲價與產值輪動、情境式停損，以及運動、親子互動與被需要感；EP706 新增 Roadster Rocket／Thrust 的技術展示與實用性拆分、晚段多頭的廣度與現金管理；EP707 新增活俠傳與創作 IP、跑步 checkpoint、SpaceX 算力回本、NAND 需求修正、載板／PCB／cleanroom／良率瓶頸，以及身體狀態與長期生活品質；EP708 新增風雨假與立場灰階、親子體驗與產品光譜、運動累積、瓶頸漲價與軟體輪動、GPU 供需／Jevons Paradox、人生折舊、家庭責任與聲音敏感。EP703-EP708 尚未逐句人工覆核，專有名詞、英文、人名、數字、贊助詞、音樂、笑話、健康、家庭與槓桿內容仍有機器轉錄風險；未來公開稿出現後應優先替換暫定稿。

## Install

Clone this repo into your skills directory:

```bash
git clone https://github.com/jaterc01/gooaye-perspective.git ~/.codex/skills/gooaye-perspective
```

For Hermes:

```bash
git clone https://github.com/jaterc01/gooaye-perspective.git ~/.hermes/skills/gooaye-perspective
```

## Usage

Trigger phrases include:

- `用股癌視角看...`
- `主委會怎麼看...`
- `Gooaye perspective`
- `gooaye-perspective`
