# gooaye-perspective

股癌 Gooaye / 謝孟恭的投資、產業觀察、生活判斷與表達操作系統。

這是一個 Codex/Hermes-style skill，基於本機 EP1-EP713 逐字稿與公開資料蒸餾，用來在使用者明確要求「股癌視角」「主委會怎麼看」「Gooaye perspective」時，輸出灰階、產業鏈、部位、風險與生活配置式的判斷框架。

`whatmkreallysaid.com` 已同步到 EP711。EP712 和 EP713 使用方格子「癌粉」的公開非官方稿，EP712 的本機轉錄檔保留作為溯源。EP712 涵蓋股災現金管理、資料中心許可與砍單傳導。EP713 新增跨波段相對強度、季線附近的反彈確認，以及遊戲投資人可提供的開發配套。方格子稿尚未逐句聽校，精確數字、人名及專有名詞引用前宜回查音檔。

## Install

Clone this repo into your skills directory:

```bash
git clone https://github.com/jaterc01/gooaye-perspective.git ~/.codex/skills/gooaye-perspective
```

For Hermes:

```bash
git clone https://github.com/jaterc01/gooaye-perspective.git ~/.hermes/skills/gooaye-perspective
```

## Usage

Trigger phrases include:

- `用股癌視角看...`
- `主委會怎麼看...`
- `Gooaye perspective`
- `gooaye-perspective`

## Notes

This skill is a simulation based on public materials and transcript analysis. It does not represent 謝孟恭本人，也不提供個人化投資建議。
