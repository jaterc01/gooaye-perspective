# gooaye-perspective

股癌 Gooaye / 謝孟恭的投資、產業觀察、生活判斷與表達操作系統。

這是一個 Codex/Hermes-style skill，基於本機 EP1-EP690 逐字稿與公開資料蒸餾，用來在使用者明確要求「股癌視角」「主委會怎麼看」「Gooaye perspective」時，輸出灰階、產業鏈、部位、風險與生活配置式的判斷框架。`whatmkreallysaid.com` 公開稿目前已同步到 EP689；EP681「人道走廊與沙沙西瓜」至 EP689「乖寶寶點數與房間裡的大象」均已用公開稿取代先前的 provisional 初校稿，EP690「EP690 | ⛳」目前是 SoundOn 的 `medium` CUDA `float16` 暫定稿，歷史 `.raw.*` 檔案若存在仍保留作為溯源。EP690 的新增判斷涵蓋 Google COT／turnkey 分帳、興趣價格邊際效用、AI 增產不等於減工、全職投資現金流壓力，以及基本面與線型互補。

## Install

Clone this repo into your skills directory:

```bash
git clone https://github.com/jaterc01/gooaye-perspective.git ~/.codex/skills/gooaye-perspective
```

For Hermes:

```bash
git clone https://github.com/jaterc01/gooaye-perspective.git ~/.hermes/skills/gooaye-perspective
```

## Usage

Trigger phrases include:

- `用股癌視角看...`
- `主委會怎麼看...`
- `Gooaye perspective`
- `gooaye-perspective`

## Notes

This skill is a simulation based on public materials and transcript analysis. It does not represent 謝孟恭本人，也不提供個人化投資建議。
